# Core baseline manifest for scaffold-repository.
#
# The single machine-readable list of files every scaffolded repository must
# carry. `scripts/verify-baseline.sh` reads this file, so the self-test and the
# documented baseline can never drift apart.
#
# One repository-relative path per line. Blank lines and `#` comments are
# ignored. A trailing marker narrows the requirement:
#
#   [public]              emitted only for public repositories
#   [symlink -> TARGET]   must be a symlink whose link text is TARGET
#
# The tracker adapter is one file with two names. `docs/agents/` holds the real
# file, matching the upstream mattpocock skill family that writes and reads it;
# `docs/issue-tracker.md` is the compatibility symlink. The pair must always
# resolve to one file - two real copies drift.
#
# Marketplace maintenance verifiers (dogfood, marketplace, scaffold-cleanup,
# workflow-cleanup) are deliberately absent: a generic consumer repo does not
# receive them.
