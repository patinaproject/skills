# Memory template

Create the missing `Email inbox triage` document in the `Agents` folder with the content below. Use the storage's native editable document format where it has one. Keep both `##` headings, which the skill uses to find each section.

```markdown
# Email inbox triage

Read on every email-inbox-triage run. Write your preferences under Rules.
The skill adds lines only under Learned. Edit or delete any of them.

## Rules

- account: me@example.com

## Learned
```

A Learned line names the date, the rule, and the evidence:

```markdown
- 2026-10-21: from `billing@vendor.example` → `Action` (you moved 1 `FYI` thread back to the inbox)
```
