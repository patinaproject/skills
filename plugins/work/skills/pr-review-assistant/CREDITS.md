# Credits

This skill builds on three skills. Two come from [HumanLayer](https://github.com/humanlayer/skills). [Dex Horthy](https://github.com/dexhorthy) wrote `show-me`.

- The [`show-me`](https://github.com/humanlayer/skills/blob/main/plugins/show-me/skills/show-me/SKILL.md) skill supplies the menu of views, such as pseudocode, call trees, diffs, and diagrams, that the owner brief picks from. The Work plugin bundles `show-me` as an upstream mirror, and the owner brief reads the installed copy.
- The [`visual-pr`](https://github.com/humanlayer/skills/tree/main/plugins/visual-pr) skill supplies the rule to show only the views that changed.
- The `teach` skill supplies the method that the PR owner uses to learn the change.
