# Triage Labels

The `triage` skill applies issue labels by their exact strings.

`issue-tracker.md` → **Labels** is the vocabulary, and is authoritative. Read
it rather than a copy here: it carries the Type, Goal, and Triage groups, the
lifecycle each Triage label implies in GitHub and Linear, the rule that a
triaged issue holds exactly one Type and one Triage label and at most one Goal,
and the Sentence case rule for label names.
